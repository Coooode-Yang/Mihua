米花 v0.5.24 · 快速开始

打开米花
从开始菜单或桌面打开“米花”，也可以双击工程根目录的“米花.exe”或“启动米花.bat”。所有入口使用同一个 BaiAgent 文件夹中的最新版。

开始使用
单击桌面小鸡打开主界面。学习、研究、日常、聊天、工具箱与最小化、关闭按钮位于同一行；顶部空白处可拖动窗口。
学习页可以专注计时、练习单词；研究页可查看 Zotero 文库、解读文献并记录科研日志；日常页管理待办和提醒。
工具箱包含网页快捷入口、文件转换和模型设置。也可以使用随手问，默认快捷键 Ctrl+Alt+Q。

模型设置
需要 AI 对话、文献解读或 AI 整理时，在“工具箱 → 模型设置”填写自己的 API Key。普通专注计时、待办、单词练习和手动记录日志不需要模型。

退出和备份
关闭主窗口后，桌面小鸡仍在运行。完整退出请选择小鸡右键菜单“退出米花”。
个人数据统一位于 BaiAgent\data。退出后备份整个 data 文件夹，保留设置、加密密钥、待办、专注和科研日志。
保留 BaiAgent 中的 _internal、runtime、licenses 和 data；不要只复制其中一个 EXE。
