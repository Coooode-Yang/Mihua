# 数据与隐私

## 数据位置

源码运行的数据保存在仓库根目录 `data/`；EXE 运行的数据保存在 EXE 所在程序目录的 `data/`。其中可能包含设置、待办、专注记录、单词进度、聊天附件、日志、文献解读与科研笔记。该目录已加入 Git 忽略规则。

退出米花后备份整个 `data/` 可以保存本地记录。不要仅复制正在使用中的 SQLite 文件，也不要将数据目录作为问题反馈附件公开上传。

## API Key

用户自行选择服务商并填写自己的 Key。选择记住时使用当前 Windows 用户的 DPAPI 加密保存；加密文件不能视作可公开内容，也不能保证换电脑后仍可解密。不要把密钥写入代码、示例、截图或 Issue。

## 模型请求

本地待办、计时、单词和桌宠互动不需要模型。主动发送的聊天内容、附件提取结果，或主动点击生成的文献阅读内容，会发送至用户选定的模型接口。图片和文档提取存在格式与截断边界，具体以界面提示为准。

## Zotero、网页与剪贴板

Zotero 集成读取本机文库元数据；文献生成需要用户主动选择。普通聊天不会自行读取整篇未提供的文献。网页摘要检索需要用户在随手问中明确启用。剪贴板解释基于用户主动复制与暂存，不提供后台页面抓取功能。

## 开源与发布

源码不包含个人数据、运行日志、真实密钥、模型权重或 Filee 二进制。测试文档与图片是项目合成样例。当前版本没有遥测或自动更新模块；后续增加联网功能时需要同步说明请求范围与数据用途。
